Song Player

One transparent circle for play and pause. The color is set in the Power BI visual format pane, under Circle > Color. There is no rectangle on the visual itself.

Download songPlayer.pbiviz Source on GitHub

Report view

Use it in a report

  1. In Power BI Desktop, open the Visualizations pane, choose Get more visuals (...), then Import a visual from a file.
  2. Select songPlayer.pbiviz (version 1.2.0.0) and add Song Player to the page.
  3. Drag the column of direct audio URLs into Song URL.
  4. Open the visual format pane and set Circle > Color. That color fills the circle.
  5. Under General > Effects, turn Background and Visual border off. Those belong to Power BI’s container. With them off, report view shows only the circle.
  6. Click the circle to play. Click it again to pause. When a song ends, the next row starts. After the last song, the circle returns to play.

Song values need to be direct http or https audio links, such as .mp3, .wav, .ogg, or .m4a.
